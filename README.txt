TMS OS by THCGaming
===================

CÀI ĐẶT DÀNH CHO NGƯỜI MỚI

1. Cài Termux từ F-Droid hoặc GitHub chính thức.
2. Chép hai file sau vào thư mục Download của điện thoại:
   - TMS_OS_Installer.sh
   - TMS_OS_ZERO_COMMAND.zip
3. Mở Termux và dán đúng một dòng:

   bash ~/storage/downloads/TMS_OS_Installer.sh

4. Khi Android hỏi quyền bộ nhớ, chọn CHO PHÉP rồi quay lại Termux.
5. Làm theo wizard tiếng Việt.
6. Sau khi hoàn tất, mở:

   http://127.0.0.1:8888

Installer tự động kiểm tra Termux, quyền bộ nhớ, Internet, file ZIP, công cụ giải nén,
bản cài hiện có, môi trường thiết bị và các dịch vụ cần thiết.

Phần chào mừng luôn hiển thị:
Welcome to TMS OS by THCGaming

Người dùng không cần thao tác cd, chmod, unzip hoặc cài package thủ công.
