TMS OS V12.2 STATIC QA REPORT
=============================

Scope
- PHP syntax: 68 files
- Shell syntax: 16 files
- JavaScript syntax: app.js and service-worker.js
- JSON parsing: RELEASE.json
- Queue worker mock execution: passed
- ZIP integrity: checked after packaging

Architecture checks
- Web request only enqueues service actions.
- Worker executes jobs independently from PHP-FPM.
- Restart All queue order puts PHP Engine last.
- Atomic rename is used when creating queue jobs and result files.
- Worker lock uses atomic mkdir and trap cleanup; old flock files are not used.
- MariaDB readiness uses mariadb-admin/mysqladmin ping with process fallback.
- Nginx config is validated before start or reload.
- PHP stop from the web UI is intentionally blocked to prevent panel shutdown.

Runtime limitation
The build environment is not Android/Termux. Real start/stop/restart behavior
must receive a final device test before this release is marked as the new stable
baseline. The package is therefore labelled stable-candidate.
