TMS OS Platform V12.2 — Service Core Rewrite
=============================================

V12.2 replaces the V12.1 synchronous service-control layer with a Termux-native
adapter and queue architecture.

Core changes
------------
1. Every Start/Stop/Restart request is written atomically to a queue.
2. A detached Bash worker executes jobs sequentially outside PHP-FPM.
3. PHP Engine restart can no longer terminate the request that submitted it.
4. Restart All order: Nginx, MariaDB, OpenSSH, Redis, PHP Engine.
5. MariaDB waits up to 25 seconds and uses mariadb-admin/mysqladmin ping.
6. Nginx validates configuration before start/reload.
7. PID and running state use service-specific Termux detection.
8. Worker results are harvested into the existing Service Manager history.

Important
---------
This package passed static syntax and archive-integrity checks. Final runtime
validation must be performed on the target Android/Termux device because the
build environment cannot execute Termux services.
